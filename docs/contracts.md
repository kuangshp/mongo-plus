# 查询与写入契约

本表描述当前封装的行为。没有封装的官方能力通过业务仓储中的 DALNative/Native 扩展；扩展调用需要业务明确维护权限、事务 Context、敏感字段及缓存失效。

| 入口 | 排序 / 投影 | Offset / Limit | Collation / Hint / Comment | Let | BatchSize / AllowDiskUse | Cache / SingleFlight |
| --- | --- | --- | --- | --- | --- | --- |
| FindList | 支持 | 支持 | 支持 | 支持 | 支持 | 显式启用 |
| FindOne / FindById | 支持 | Offset 生效，最多一条 | 支持 | 支持 | 通过 Find 限一条实现 | 显式启用 |
| Exists | 最终固定主键投影 | Offset 生效，最多一条 | 支持 | 支持 | 沿用 FindOne | 显式启用 |
| Count | 不参与计数 | 不参与计数 | 支持 | 拒绝 | 列表专属项不参与计数 | 显式启用 |
| Walk | 支持 | 支持 | 支持 | 支持 | 支持 | 拒绝 |
| 原始 Aggregate | 最终结果阶段 | 最终结果阶段 | 支持 | 支持 | 支持 | 拒绝 |
| From / Scan | 最终结果阶段；Sort 可在中途 | 最终结果阶段 | 根命令支持；Lookup 子命令拒绝 | 根命令支持 | 根命令支持 | 拒绝 |
| 普通 Update / Delete Wrapper | 拒绝 | 拒绝 | 支持，软删除保持一致 | 支持 | 拒绝 | 拒绝 |

Count 的列表专属选项被明确忽略，方便 FindPage 在相同过滤范围内统计总数；其他入口不以静默忽略替代支持。FindPage 的 page/size 覆盖列表 Offset/Limit；关联 ScanByPage 拒绝同时指定 Offset/Limit。

字符串主键的稳定分页使用 simple（二进制）Collation，覆盖集合默认规则；显式语言 Collation 返回错误。展开关联分页存在字符串主键时同样限制，Lookup 数组不作为展开行的排序键。需要语言排序又需要稳定分页时，使用数值/ObjectID 唯一键，或在原生扩展设计额外唯一排序键和游标。分页不自动提供快照；一致的总数与列表需要 snapshot 事务。

## 删除与隔离

| 标记 | 读取范围 | 删除方式 | 租户 / 权限 |
| --- | --- | --- | --- |
| 默认 Context | 正常记录 | 集合开启软删除时逻辑删除 | 保留 |
| DALUnscoped | 包含已删除记录 | 仍遵守集合软删除配置 | 保留 |
| DALPhysicalDelete | 正常记录 | 显式物理删除 | 保留 |
| 两者组合 | 包含已删除记录 | 显式物理删除 | 保留 |

DAL 每次操作只解析一次 Provider；分页的数据、计数、隔离与写后失效使用同一数据库包装器。事务和 Repository.WithDAL 的显式绑定优先。多集合子管道需要扩展仓储自行处理子集合范围。

## 缓存与敏感字段

| 约束 | 行为 |
| --- | --- |
| SF 参数 | 递归保留类型，map 规范排序，数组与 BSON D 保持顺序；编码失败返回 ErrInvalidCacheArgs |
| SF 自定义 JSON 类型 | 以公开 JSON 编码契约表示值；依赖未编码状态的加载器必须补充明确 Args |
| SF 返回值 | 同名查询应固定返回类型；并发合并区分返回类型。公共 SF 结果按既有约定视为不可变对象 |
| Repository 本地缓存 | 保存 Go 值快照，每个调用者获得独立副本 |
| Repository 共享缓存 | 自定义 BSON 方法/动态类型直接回源；其他值保存前验证无损 BSON 往返，不满足时不保存共享条目 |
| 共享缓存命名空间 | 同一实际数据源、权限与编解码配置才能共享；键升级后不读取旧条目 |
| 加密字段 | EncryptAtRest=true 必须使明文 bson:"-"；存储路径必须匹配标签且不能重叠 |
| 日志 | 默认按字段脱敏；表达式、变量和脚本隐藏常量。严格隐藏所有参数使用 HideParameters |

缓存版本发布与业务写入不是跨进程原子协议，关键一致性场景使用 CacheConfig.Disabled。该配置不等于关闭公共 SF；业务不能再另行使用 SF 缓存关键查询。

## 验证范围与原生扩展

回归覆盖嵌套 BSON 类型租户键、并发 SF、缓存前后值一致性、删除范围与方式矩阵、默认 Collation、聚合与官方驱动结果差分、敏感字段拒绝落明文和表达式日志。

高级更新的 ArrayFilters/更新管道/绕过文档校验、特殊集合、流式游标细项、特殊索引属性及生成器未映射的 BSON 类型仍按 DAL/Native 的明确扩展范围接入。不能将“有原生扩展入口”表述为“所有方法和属性都已封装”。
